# Peeky

A Windows-first background productivity app — break timers, tab parking, and handoffs, all from the system tray.

## Requirements

- Python 3.11
- Windows 10/11

## Setup

```bash
git clone <repo-url>
cd peeky/peeky
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
